# 🩺 HealthDiary

A simple web application for tracking personal health data.

Users can monitor sleep, calculate BMI, and maintain a personal health diary.

## ✨ Features

- 👤 User registration
- 🔐 Login and logout
- 😴 View average sleep
- ⚖️ BMI chart
- 🧮 BMI calculator
- 📓 View diary entries
- ➕ Add diary entries
- ❌ Delete diary entries
